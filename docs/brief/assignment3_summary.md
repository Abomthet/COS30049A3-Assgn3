# Assignment 3: Full-Stack Web Development for AI Application in Cybersecurity Scenarios

## Assignment Overview
- **Weight:** 45% of your total marks for the unit
- **Due Date:** Sunday, Week 12
- **Context:** As the culminating assignment of the course, this project carries the largest weight in the final grade. It tests students’ ability to integrate front-end and back-end technologies, handle data efficiently, and deliver clear visualizations of an AI model's output.

## Core Areas of Proficiency
1. **Full-Stack Web Development:** Implement a complete web application using React.js for the user interface and FastAPI for server-side processing. The front end must capture user inputs, and the back end must handle the AI model’s processing and return prediction results.
2. **AI Model Integration:** Connect the AI model to the FastAPI back-end, enabling real-time predictions based on user input data. This involves passing data between front-end and back-end and efficiently processing it.
3. **Data Visualization:** Use React.js along with visualization libraries like D3.js, Chart.js, or Plotly.js to present predictions dynamically with clear insights (at least two types of charts required; three required for HD-level work).
4. **Error Handling and Input Validation:** Ensure robust error handling and input validation in both front-end and back-end.

---

## Cybersecurity Project Focus Areas
Students' applications may focus on one of the following areas:
1. **Misinformation Detection on Social Media:** Detect false or misleading posts to improve online safety.
2. **Spam or Malware Detection:** Detect spam messages or potential malware threats using datasets containing emails, messages, or files.
3. **Detecting Software Vulnerabilities:** Analyze source code patterns to automatically flag risky code and bugs.
4. **Network Traffic Classification for Anomaly Detection:** Classify network traffic to distinguish normal behavior from malicious anomalies.
5. **Cybersecurity Threat Detection in Banking:** Research and solve a specific banking cybersecurity problem (e.g., fraud detection, identity theft) using AI engineering.

## High Distinction (HD) Requirements
To achieve an HD, students must include:
- At least three types of charts with interactive features (e.g., zoom, filtering) using D3.js or Plotly.js.
- Real-time updates (live data feeds or auto-refreshing charts).
- Custom user input forms with comprehensive validation and dynamic feedback.
- Robust error handling with clear, informative messages on both tiers.
- UX enhancements (e.g., export functionality for predictions and visualizations).
