# Modifications for the web

Assignment 2's runtime in `explorer/`, `lm/`, `models/`, `data/` and `reports/` is copied unchanged from
commit `aa56a26` (tag `v1.0`) by `tools/vendor_a2.py`; `A2_VENDOR.json` holds the SHA-256 of every file and
`tests/test_vendor_integrity.py` recomputes them. Every change made for the web is in `app/` or is listed
here, with the test that covers it. Numbers refer to plan section 7.5.

| Mod-9 | `services/assistant_service.py` serves E12 (`POST /api/explanations`) and E1's `assistant` state. The 152M model loads on first use (`explorer.predict.load_writers`, in the worker thread of that request; E1 says `loading` meanwhile) and PyTorch is imported only then. One answer is written at a time: a second request that would have to write gets 429 `rate_limited` with `Retry-After` (the new `RateLimited` error in `core/errors.py`); answers from memory or the prepared file never wait. Answers are cached, 512 at most, by the SHA-256 of the facts the prompt is built from (`explorer.assistant.summary`); greedy decoding makes the same facts give the same answer, and a failed attempt is cached too. The guardrail is A2's `explorer.assistant.explain`, called as it is; the service keeps only the names of the failed checks, so a rejected answer is never returned and the template comes back. The text served is reworded as the template is (Mod-12), after the guardrail has judged the writer's own words. `EXPLORER_ASSISTANT` defaults to `auto` again (on when the weights and PyTorch are installed); with the Assistant off or not installed E12 answers 200 with the template and `skippedWriters` says why | Writing takes about 3 s of CPU (10 s with the load); two at once would double it. A web service must not fail because an optional 610 MB file is absent, and must not show text no check has judged | `test_assistant_api.py` (every status, each guardrail check, the failure never returned, 429 while loading and while writing, cache hits and eviction, off, not installed, a model that cannot be loaded, the wording rule over E12 bodies; one `slow` test on the real model), `test_system_api.py::test_capabilities_follow_the_switches`, `test_config.py` |
